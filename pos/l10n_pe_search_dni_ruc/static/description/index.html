Búsqueda RUC/DNI

Este módulo permite la búsqueda, validación y actualización de datos de RUC y DNI en Perú utilizando servicios de terceros.

Características Principales
  • Configuración de búsqueda personalizada: Permite seleccionar el proveedor de búsqueda de RUC/DNI.
Configuración del Servicio de Búsqueda

Para configurar el servicio de búsqueda, sigue estos pasos:

  1. Ir a Ajustes.
  2. Hacer clic en Usuarios y compañías y luego en Compañías.
  3. Seleccionar Servicio de búsqueda.
  4. Escoger la API deseada.
  5. Ingresar el Token correspondiente.
Proveedores de Servicio

Los proveedores disponibles para el servicio de búsqueda son:

  • API Peru - https://apiperu.dev
  • Api Migo - https://api.migo.pe
  • JSON PE - https://json-pe.com
